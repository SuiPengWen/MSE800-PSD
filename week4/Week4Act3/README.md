Use Case Diagram 1: Account and Wallet Management
This diagram shows the main account and wallet management functions of the finance money exchange application. The main actor is the Customer. The customer can register, log in, update personal information, manage login credentials, create wallets, and view wallet balances. This diagram is based on the Customer, UserCredential, and Wallet entities from my W3-A2 ERD.

Use Case Diagram 2: Money Exchange and Rate Alert Management
This diagram shows the money exchange and rate alert functions of the application. The main actor is the Customer. The customer can exchange currency between wallets, view transaction history, and create rate alerts. The exchange currency use case includes selecting a source wallet, selecting a destination wallet, and entering the source amount. The rate alert use case includes setting the base currency, target currency, and target rate threshold. This diagram is based on the ExchangeTransaction, Wallet, RateAlert, and Customer entities from my W3-A2 ERD.
